# Fundación Casanare — Tema WordPress (v2.0.0)

Tema de bloques (Full Site Editing) para WordPress 6.6 o superior. Usa el contenido real del Plan Estratégico de la fundación. Todo se edita desde el panel, sin tocar código.

## Instalación
1. Apariencia → Temas → Añadir nuevo → Subir tema → elige `fundacion-casanare.zip` → Activar.
2. Al activarlo, el tema hace esto una sola vez:
   - Importa el logo, el icono del sitio y 17 fotos a la Biblioteca de medios.
   - Crea las páginas Inicio, Quiénes somos, Líneas estratégicas, Galería, Súmate, Contacto, Noticias y Política de datos.
   - Crea los menús "Menú principal" y "Menú del pie".
   - Publica dos noticias: el convenio con UNIMINUTO (2017) y el Plan Estratégico.
   - Fija Inicio como portada y Noticias como página de entradas.
3. Ajustes → Enlaces permanentes → "Nombre de la entrada" → Guardar.

## Dónde se edita cada parte
| Qué | Dónde |
|---|---|
| Logo | Apariencia → Editor → Patrones → Encabezado (bloque Logo del sitio). También en Personalizar → Identidad del sitio |
| Eslogan ("Para hacer las cosas bien") | Ajustes → Generales → Descripción corta |
| Nombre del sitio | Ajustes → Generales → Título del sitio |
| Icono del navegador | Ajustes → Generales → Icono del sitio |
| Menú principal y menú del pie | Apariencia → Editor → Navegación |
| Encabezado y pie (contacto, redes, textos) | Apariencia → Editor → Patrones → Partes de plantilla |
| Textos e imágenes de cada página | Páginas → editar la página. Cada sección es un bloque |
| Colores y tipografías | Apariencia → Editor → Estilos |
| Noticias | Entradas → Añadir nueva |
| Secciones reutilizables | Insertador (+) → Patrones → "Fundación Casanare" |

## Datos pendientes (marcadores)
Reemplaza estos marcadores con los datos reales:
- Dirección de la sede
- Correo `contacto@fundacioncasanare.org`
- Teléfono / WhatsApp `+57 300 000 0000`
- Enlaces de Facebook e Instagram
- NIT y cuenta bancaria (página Súmate)

Revisa la Política de datos con tu asesor legal.

## Formularios
Los formularios de Contacto y Voluntariado abren el correo del visitante (`mailto`). Para recibir los mensajes en el panel, instala un plugin como WPForms o Contact Form 7 y cambia el bloque HTML por el formulario del plugin.

## Paleta
Los colores salen del logo: rojo #C4161C, verde #2E7D32, verde lima #7CC242, amarillo #F5B315 y negro #1B1B1B, sobre un blanco cálido #FCFAF6.

Tipografías: Zodiak (títulos), General Sans (texto) y Kalam (eslogan manuscrito). Todas van incluidas en el tema, sin conexión a servicios externos.
